Gerenciador de Tarefas
Sistema de gestão de tarefas básico desenvolvido em Python como projeto da disciplina de Programação com Python.

Funcionalidades:
Adicionar tarefa — cadastra uma nova tarefa com descrição, prazo, prioridade e data de criação automática
Listar tarefas — exibe todas as tarefas cadastradas com seus detalhes
Concluir tarefa — marca uma tarefa como concluída pelo ID
Remover tarefa — exclui uma tarefa da lista pelo ID

Como rodar:

Clone o repositório:
bashgit clone https://github.com/thiagomiorelli-spec/gerenciador-tarefas.git

Acesse a pasta do projeto:
bashcd gerenciador-tarefas

Execute o programa:
bashpython gerenciador_tarefas.py

Não é necessário instalar nenhuma biblioteca externa.

Tecnologias:
Python 3
Módulo datetime (nativo do Python)

Conceitos aplicados:
Funções com parâmetros e DocStrings
Manipulação de listas e dicionários
Loops for e while
Estruturas de decisão if, elif e else
Tratamento de entradas inválidas
